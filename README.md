# DEPI Frontend Tasks

This repository records hands-on frontend exercises from the DEPI training track. The work progresses from foundational HTML through forms, responsive page composition, and browser-side JavaScript.

## Contents

| Session | Focus |
| --- | --- |
| `SESSION_01` | HTML page structure, navigation, images, and introductory assignments. |
| `SESSION_02` | Login and registration form layouts. |
| `SESSION_03` | Responsive fruits-shop landing page with local assets. |
| `SESSION_04` | JavaScript lab exercises. |
| `SESSION_05` | Additional JavaScript tasks. |

## Run locally

These are static exercises and do not need package installation or a build step. Open an HTML file directly in a browser, or serve the repository with a local static server:

```powershell
python -m http.server 8080
```

Then open the exercise you want to review, for example:

```text
http://localhost:8080/SESSION_03/index.html
```

## Notes

Each session is independent. Start with the HTML file inside the relevant session folder rather than expecting one application entry point.
